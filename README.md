# Base para projeto:
- **Cadastro de usuários**
- **Login com autenticação JWT**

## Tecnologias Utilizadas

- **Spring Boot 3.2.3**
- **Spring Security**
- **JWT (jjwt 0.12.3)**
- **BCryptPasswordEncoder** para hashing de senhas
- **PostgreSQL** como banco de dados
- **Maven** para gestão de dependências
